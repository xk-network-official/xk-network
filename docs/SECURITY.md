# Security Guidance

## Official contract

XK Token (XKT) on BNB Smart Chain:

`0x603a874c9b7810bcd1ff7ce06cea0f2af3c8d1be`

Verify the address and published source on [BscScan](https://bscscan.com/token/0x603a874c9b7810bcd1ff7ce06cea0f2af3c8d1be) before interacting.

## Protect yourself

- XK Network will never ask for a seed phrase or private key.
- Do not trust unsolicited support messages or replacement contract addresses.
- Confirm announcements through at least two official sources.
- Contract source verification proves that published source matches deployment bytecode; it is not an audit or endorsement.
- Digital tokens can lose all value. Users remain responsible for wallet security and applicable laws.
